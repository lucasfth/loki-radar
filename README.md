# Loki Radar

Daily machine-curated tech radar behind [lucashanson.dk/radar](https://lucashanson.dk/radar).

Sources: RSS and Bluesky feeds, Reddit (via Redlib), GitHub (releases of starred repos, trending, rising new repos), Hacker News, Lobsters and Hugging Face daily papers. A local Qwen model scores each item against an interest profile and writes a short summary.

- `public.json`: latest output, read by the website

Runs twice a day on a home server.
